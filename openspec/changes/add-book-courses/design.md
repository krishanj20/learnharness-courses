## The learner’s path

| Where | What the learner sees |
| --- | --- |
| Courses → Create course | Pick a PDF. Review the book title, chapters and any uncertain page boundaries. |
| Book | Each chapter shows what it teaches, whether to cover or skip it, and the evidence behind that advice. Both choices can be changed. |
| Chapter chat | Open the assigned pages, confirm the reading, then discuss one question at a time. Each section returns to the reading step. |
| Chapter exam | Attempt the book’s exercises. If the chapter has none, the tutor writes questions. Each exercise uses its published solution when available, or a checked tutor-derived answer. Request help, work through a smaller step and return to the whole problem. See which objectives still need practice. |

## Agreed delivery

A **Courses** sidebar action opens a plugin-owned book library on stock LearnHarness. The plugin stores the chapter chats and uses the configured host model for planning and live Socratic tutoring. Imported pages, transcripts and progress are readable offline. The host continues to list native sessions under Teaching, Practice and All.

## Placement evidence

Use the graph to locate related sessions. Read the learner’s actual answers to identify which chapter objectives they demonstrated independently. Offer a short diagnostic where evidence is missing or mixed. The learner can go straight to the reading.

## Repository

The proposed repository name is **learnharness-courses**. Package the plugin for installation in Community plugins, following the offline plugin’s distribution model.
